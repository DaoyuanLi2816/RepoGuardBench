Defenses for Local Coding Agents**
Daoyuan Li (University of Minnesota Twin Cities).

- Final camera-ready PDF: [`main.pdf`](main.pdf)

Accepted at the **5th Deep Learning for Code (DL4C) Workshop at ICML 2026**.
DL4C is a **non-archival** workshop: this paper is **not** part of the ICML
main-conference PMLR proceedings. Please cite it as a workshop presentation
(`@misc`), not as a PMLR `@inproceedings` entry.

The LaTeX source is not included in this artifact. Tables and figures can be
regenerated from the bundled aggregate results with `make reproduce-tables`
and `make reproduce-figures` (see the repository `README.md` and
`docs/REPRODUCIBILITY.md`).
`make verify-paper` checks the PDF hash together with the released headline
results.
